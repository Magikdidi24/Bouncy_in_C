# Bouncy_in_C

A ball falling with gravity and bouncing off the edges of the window. It leaves a red trail of its last 1000 positions, and the bounces don't lose any speed.

Press space for rainbow mode (random color on every pixel of the ball and the trail). The ball's height and vertical speed get printed in the terminal every frame.

Only needs SDL2. `make` compiles and runs it:

```bash
make
```
